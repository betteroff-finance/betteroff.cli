␛[1mbetteroff estimate-quarterly-tax␛[22m  Estimate quarterly tax

Use this when the user asks how much federal estimated tax to pay each quarter or about safe harbor.
Compute US federal quarterly estimated tax by safe harbor from figures the user states. Ask for
missing figures; never guess. Pass filingStatus only when the user stated it; otherwise null.
