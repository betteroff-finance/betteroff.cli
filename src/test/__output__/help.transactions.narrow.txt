␛[1mbetteroff transactions␛[22m  Search transactions

Use this when the user asks to find transactions or total a
filtered set of transactions. Search transactions by date,
merchant, category, trait, type/class, account, amount, or
whether they need a category; a summary totals all matches.
Brokerage deposits/withdrawals: transactionClass
`brokerage`, transactionTypes
`transfer_in`/`transfer_out`/`deposit`/`withdrawal`.
