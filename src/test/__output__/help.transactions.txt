␛[1mbetteroff transactions␛[22m  Search transactions

Use this when the user asks to find transactions or total a filtered set of transactions. Search
transactions by date, merchant, category, trait, type/class, account, amount, or whether they need a
category; a summary totals all matches. Brokerage deposits/withdrawals: transactionClass
`brokerage`, transactionTypes `transfer_in`/`transfer_out`/`deposit`/`withdrawal`.

␛[1mFlags␛[22m
  --all-time
␛[2m      Use true for all synced merchant history; dates are ignored. Use it when the answer may be␛[22m
␛[2m      older than the default 30 days: the last or first time, ever, annual or one-off charges, or␛[22m
␛[2m      'did I pay X before'.␛[22m
  --cursor <text>
␛[2m      Pass page.nextCursor unchanged, with the same filters. Leave out for the first page.␛[22m
  --start-date <text>
␛[2m      Start date (ISO format, e.g. 2025-01-01). Leave out for 30 days ago.␛[22m
  --end-date <text>
␛[2m      End date (ISO format). Leave out for today.␛[22m
  --merchant <text>
␛[2m      Merchant name to search for (partial match).␛[22m
  --traits <a,b>
␛[2m      Only transactions whose merchant has every listed trait. Use for purposes a category does not␛[22m
␛[2m      capture. discretionary: optional spending: dining out, entertainment, hobbies, shopping for␛[22m
␛[2m      wants; travel: trips: flights, hotels, rental cars, cruises, travel booking; health: medical␛[22m
␛[2m      care: doctors, dentists, pharmacies, vision, therapy; kids: children: childcare, schools,␛[22m
␛[2m      tutoring, toys, kids' activities; gifts: gifts: florists, gift shops, gift cards; charity:␛[22m
␛[2m      donations: charities, nonprofits, religious organizations, fundraisers; business: work␛[22m
␛[2m      expenses: software, office supplies, coworking, professional services; crypto: crypto:␛[22m
␛[2m      exchanges, on-ramps, wallets, crypto cards. Person-to-person payments and unrecognized␛[22m
␛[2m      merchants carry no traits. Leave out for no trait filter.␛[22m
␛[2m      One of: discretionary, travel, health, kids, gifts, charity, business, crypto␛[22m
  --category <text>
␛[2m      Category code (e.g. FOOD_AND_DRINK, TRANSPORTATION, ENTERTAINMENT).␛[22m
  --transaction-types <a,b>
␛[2m      Filter by transaction type. Bank and card income (paychecks, benefits) is type deposit with␛[22m
␛[2m      category INCOME; for income totals use betteroff_get_cash_flow, and to list income rows use␛[22m
␛[2m      category INCOME. fee and interest_payment also match the bank-fees category, so card interest␛[22m
␛[2m      charges and ATM fees are found. For investment account deposits/withdrawals, use␛[22m
␛[2m      transfer_in/deposit/bank_deposit for deposits and transfer_out/withdrawal/bank_withdrawal for␛[22m
␛[2m      withdrawals.␛[22m
␛[2m      One of: bank_deposit, bank_withdrawal, card_charge, card_refund, ach_transfer, wire, check,␛[22m
␛[2m      atm, cash, interest_payment, fee, buy, sell, short_sell, buy_to_cover, swap, dividend,␛[22m
␛[2m      qualified_dividend, capital_gain_distribution, return_of_capital, interest, bond_coupon,␛[22m
␛[2m      airdrop, fork, staking_reward, mining_reward, lending_reward, nft_mint, nft_sale,␛[22m
␛[2m      nft_purchase, lp_mint, lp_burn, lending_supply, lending_borrow, lending_repay, transfer,␛[22m
␛[2m      bridge_out, bridge_in, split, spin_off, merger_proceeds, rights_issue,␛[22m
␛[2m      manual_valuation_change, other, payment, refund, deposit, withdrawal, receive, send,␛[22m
␛[2m      transfer_in, transfer_out␛[22m
  --needs-review
␛[2m      Use true to list posted transactions that need a category: no category, OTHER or␛[22m
␛[2m      UNCATEGORIZED, or an automatic category below 50% confidence that nobody confirmed. Ledger␛[22m
␛[2m      review items (unmatched transfers, unnamed assets) are counted by cause in␛[22m
␛[2m      betteroff_get_overview ledger.reviewGroups. Leave out for no filter.␛[22m
  --transaction-class <bank|brokerage|crypto_exchange|blockchain_wallet>
␛[2m      Filter by normalized transaction class. Use brokerage for investment accounts.␛[22m
  --account-id <text>
␛[2m      Filter to a specific account by ID. Leave out for search all accounts.␛[22m
  --min-amount <json>
␛[2m      Minimum transaction amount, as a number or decimal text. Must not exceed maxAmount.␛[22m
  --max-amount <json>
␛[2m      Maximum transaction amount, as a number or decimal text.␛[22m
  --limit <integer>
␛[2m      Max results to return (default 25, max 50). Leave out for 25.␛[22m
